# What changes consumption

::text::

<div class="mc-stack" data-slide-id="S04">

<!--
Timebox: 15 minutes

Talk track: What could you change without weakening the result you need? This receipt is an illustration, not a measured run. Model choice and relevant context shape the request. Reveal the work: a bounded workflow avoids unnecessary steps, while cache behavior can vary. Reveal the output and then the evidence. A shorter response is useful only if it still satisfies the task. Keep the task and acceptance criteria fixed, and change one or two levers, not everything at once. Use three minutes for the receipt, eight for participants to describe a fair comparison, and four to review what they could actually observe. Record the usage source and the quality check together.

Response guidance: If the suggestion removes needed context, say, “Would the result still pass the same check?” If an exact saving is proposed, say, “Record the observation and its limits. Token counts and one run do not establish a bill or a saving.”

Payoff: Participants can propose a bounded comparison rather than equating smaller requests with demonstrated value.
